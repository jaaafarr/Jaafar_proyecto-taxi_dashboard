# Jaafar-Bousaid-dashboard

Este proyecto permite visualizar un EDA básico del dataset NYC Taxi a través de una aplicación Flask.

## Estructura
```
dashboards/Jaafar-Bousaid-dashboard/
├── app.py
├── templates/
│   └── index.html
└── README.md
```

## Uso
1. Coloca `nyc_taxi.csv` en el mismo directorio que `app.py`.
2. Instala dependencias:
   ```
   pip install flask pandas
   ```
3. Ejecuta la aplicación:
   ```
   python app.py
   ```
4. Abre en el navegador:
   ```
   http://127.0.0.1:5000/
   ```
